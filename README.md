# 🔮 Customer Churn Predictor

A machine learning web app that predicts whether a telecom customer 
will churn and explains **why** using SHAP explainability.



## 📊 Features
- Predicts churn probability for any customer
- SHAP waterfall chart explaining each prediction
- Top risk factors increasing/reducing churn
- Built with Logistic Regression (ROC-AUC: 0.86)

## 🛠️ Tech Stack
- Python, Scikit-learn, SHAP
- Streamlit for deployment
- Telco Customer Churn Dataset (Kaggle)
